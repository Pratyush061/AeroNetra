## 2026-08-12 - [Missing Skip to Content Links]
**Learning:** Next.js application structures do not inherently provide keyboard accessibility for skipping repetitive navigation. This can leave keyboard users stranded traversing the header before reaching the actual page content.
**Action:** Always implement a visually-hidden, focusable 'Skip to content' link at the top of the body tag, and ensure semantic HTML is structurally separated from site navigation.
